# Catalog Skill

Daftar skill yang tersedia di repo ini. Agent membaca `SKILL.md` dari folder
skill yang dibutuhkan, lalu menjalankan sesuai instruksi di dalamnya.

| Skill | Deskripsi |
|---|---|
| template | Template untuk membuat skill baru |
| makefun | Entri bounty make.fun |
| research | Cari + ringkas berita/riset/harga |
| web-check | Ambil & ringkas isi halaman web |
| compile | Bangun / proses project |
| hold | Jaga proses tetap berjalan di luar sesi terminal |
| pdf-reader | Baca dokumen PDF |
| summarize | Ringkasan teks → poin (contoh lengkap) |

## Validasi

```bash
python scripts/validate-skills.py
```
