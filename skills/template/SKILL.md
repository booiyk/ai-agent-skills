## Kapan
Gunakan template ini saat membuat skill baru yang belum ada di repo.

## Langkah
1. Salin folder ini ke `<nama-skill>/`.
2. Ganti `name`, `version`, `description` di `SKILL.md`.
3. Isi instruksi: langkah kerja, CLI, contoh, batasan.
4. Tambah `scripts/` atau `references/` bila ada file pendukung.

## Referensi
SKILL.md - template ini.
